</p>

## 📌 Sobre o projeto

O **PawCare – Gestão Pet** é um aplicativo mobile desenvolvido com Flutter e Dart, criado como projeto acadêmico para a avaliação V2 do curso de Análise e Desenvolvimento de Sistemas (ADS).

O objetivo é facilitar o gerenciamento de um Pet Shop, reunindo em um único aplicativo o cadastro de animais, informações dos tutores, serviços disponíveis e agendamentos.

O projeto foi desenvolvido com foco em uma interface moderna, elegante e intuitiva, proporcionando uma experiência simples e agradável ao usuário.

## ✨ Funcionalidades

- 📊 Dashboard com indicadores e informações gerais.
- 🐶 Cadastro e listagem de animais.
- 🔎 Pesquisa e filtros por espécie.
- 📝 Visualização dos detalhes dos animais.
- ✏️ Edição dos cadastros.
- 🗑️ Exclusão de animais com confirmação.
- 🛁 Catálogo de serviços e preços.
- 📅 Criação e gerenciamento de agendamentos.
- ✅ Validação de formulários.
- 📱 Navegação entre as telas do aplicativo.

## 🛠️ Tecnologias utilizadas

## 📱 Telas do aplicativo

O projeto possui seis telas principais:

1. Dashboard
2. Listagem de animais
3. Detalhes do animal
4. Cadastro e edição de animais
5. Serviços
6. Agendamentos

## 🔄 CRUD de animais

O aplicativo implementa as quatro operações fundamentais de gerenciamento de dados:

- **Create:** cadastro de novos animais.
- **Read:** consulta e visualização dos animais cadastrados.
- **Update:** edição das informações dos animais.
- **Delete:** exclusão de registros com confirmação.

## 🚀 Como executar o projeto

É necessário ter o Flutter SDK instalado e configurado.

Clone o repositório:

```bash
git clone https://github.com/DyegoAlcantara-2026/PawCare.git
```

Entre na pasta:

```bash
cd PawCare
```

Instale as dependências:

```bash
flutter pub get
```

Execute no Chrome:

```bash
flutter run -d chrome
```

Para analisar o código:

```bash
flutter analyze
```

## 💾 Armazenamento de dados

O projeto utiliza dados mockados para demonstrar as funcionalidades. Não possui integração com API ou banco de dados.

Os registros são mantidos em memória durante a execução e podem ser reiniciados ao fechar ou recarregar o aplicativo.
